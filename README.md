# Panini.rs

A library and associated cli tools for:
+ Translating ASCII XSampa to properly formatted Unicode IPA.
+ Translating IPA symbols+diacritics into their phonological features using a representation inspired by feature geometry.
+ Translating IPA transcriptions in XSampa or IPA to Phonological Words consisting of a list of symbolic and featural representations.
+ Defining and applying sound changes to vocabulary using both symbolic substitution and phonological transformation.

# Usage

Use this at your own peril, it is a work in progress and is very poorly documented. This was originally a project I used to learn rust and it shows in the several layers of nonsense I have written.

On the other hand, what works works well enough 🤷
